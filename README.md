# Portfolio Website

A clean and modern portfolio website showcasing my software development projects.

## 🌟 Features

- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- **Modern UI**: Clean and professional interface with smooth animations
- **Project Showcase**: Displays 3 projects with descriptions, tech stacks, and links
- **Contact Section**: Easy ways to get in touch via GitHub, LinkedIn, and Email

## 📦 How to Use

1. Clone this repository
2. Open `index.html` in your web browser
3. Or deploy to GitHub Pages for live hosting

### Viewing Locally
Simply open the `index.html` file in any modern web browser.

### Deploying to GitHub Pages
1. Go to your repository Settings
2. Navigate to Pages section
3. Select your branch (main/master)
4. Save and wait for deployment
5. Your portfolio will be live at `https://yourusername.github.io/repository-name`

## 🎨 Customization

The portfolio is built with clean, modular code that's easy to customize:

### Colors
Edit the CSS variables in `styles.css`:
```css
:root {
    --primary-color: #2563eb;
    --secondary-color: #1e40af;
    /* ... more variables */
}
```

### Content
Update `index.html` to modify:
- Personal information
- Project descriptions
- Contact links
- Social media profiles

### Layout
The design is fully responsive and uses CSS Grid for the project cards layout.
